Editing a row's % or Amount both waterfall the difference against the last leg the same way: on any OTHER leg, increasing it decreases the last leg by the same amount and decreasing it increases the last leg — always the last leg directly, never the leg next to it. Editing the last leg itself works the other way: decreasing it opens a brand-new leg to hold the difference; increasing it draws from the leg(s) before it, as far back as needed. No leg's % or Amount is ever pushed below 0. % moves in whole percentage points only — for a finer split, use Amount instead. Either way this side always totals exactly {{ totalAmount }} {{ transactionCurrency }}.
