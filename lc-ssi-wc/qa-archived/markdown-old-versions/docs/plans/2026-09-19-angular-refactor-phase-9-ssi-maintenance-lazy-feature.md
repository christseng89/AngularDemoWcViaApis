# Angular Refactor Phase 9 SSI Maintenance Lazy Feature Implementation Plan

> For Codex: execute Red → Green → Refactor task by task directly on `refactor` under the Product Owner's explicit branch instruction; obtain independent exact-commit review before closure.

**Goal:** Complete Phase 9 root dependency closure: SSI Maintenance, Payment and FIN feature ownership must leave the root `AppComponent` while preserving existing routes, business behavior, API contracts and WIP protection.

**Architecture:** Keep the `x-ui-resources` governed maintenance pattern separate from `ResolutionPageDefinition`. A feature-scoped facade owns SSI index and Maker state and coordinates the existing HTTP-only `SsiMaintenanceApiService`; route components render the existing Dashboard and Maker UI without new business rules. The root retains shell navigation, Checker count and the shared read-only detail bridge only until those consumers have their own bounded slices. The existing route-guard bridge must invoke the same fail-closed WIP cancellation before URL or saved-view state commits.

**Tech Stack:** Angular 22 standalone lazy routes, Signals, Formly, TypeScript 6, Jest 30 and Nx 23.

**Base:** `refactor` commit `ad5c1c31532076d22f5539d5a9a23f2188fc11ba`. No new branch or Push under the Product Owner's explicit instruction. No backend, DB, fixture, seed, OAS, design-token or `SwiftDataCrudComponent` change. The Product Owner's later Phase 9 Final Slimming directive explicitly adds behavior-preserving Payment／FIN root ownership migration; it does not authorize business-rule, API-contract or approved UI changes.
