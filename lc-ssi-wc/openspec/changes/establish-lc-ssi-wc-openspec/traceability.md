# Requirement Traceability Matrix

## Status Vocabulary

- `PROVEN`: requirement is supported by the cited current contract/implementation/tests within its stated scope.
- `PARTIAL`: observable behaviour is evidenced, but public contract, browser denominator or governance acceptance is incomplete.
- `NOT_PROVEN`: insufficient evidence for a current requirement; such claims are excluded from baseline specs.
- `DISCREPANCY`: authoritative sources or implementation/contract surfaces conflict.
- `NOT_APPLICABLE`: a trace column does not apply to the capability.
